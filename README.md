# Simple Shooting Game

HTML/CSS/JavaScript で作った簡単なシューティングゲームのサンプルです。

特徴
- スマホ向けタッチ操作（左下に仮想ジョイスティック、右下に発射ボタン）
- キーボード操作（左右・スペース）にも対応
- GitHub Pages で簡単に公開可能

ローカルでの確認:
1. ファイルをクローンまたはダウンロード
2. プロジェクトルートで簡易 HTTP サーバーを立てる（ブラウザで file:// よりもサーバー経由が安定します）
   - Python 3: `python -m http.server 8000`
   - または VSCode の Live Server 拡張など
3. ブラウザで http://localhost:8000 を開く

公開（GitHub Pages）:
1. Files are already pushed to this repository.
2. GitHub のリポジトリページ → Settings → Pages に移動
3. Source を "main" ブランチ、root (/) を選択して Save
4. 数分で `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` で公開されます

問題があれば私が続きを手伝います（外部設定が必要な場合は指示してください）。
